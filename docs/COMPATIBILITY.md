# Compatibility and Semantic Boundaries

Status: CURRENT. This document tracks the compatibility status of tested titles
and runtime subsystems in Nakagawa Recomp. It names every semantic boundary and
tracking issue, following the project's fail-closed policy: unsupported behavior
fails cleanly at a named boundary and is never faked.

## Title compatibility

The table below lists source-owned fixtures, showcase demos, the verified flagship,
and uncatalogued retail discs. Nakagawa Recomp makes no claim of retail title
playability out of the box from an ISO alone ([`ISSUES.md`](../ISSUES.md)).
Uncatalogued discs import as **Experimental** with fail-closed checklists.

| :--- | :--- | :--- | :--- |

## Subsystem compatibility

Every subsystem state is derived from maintained engineering contracts and live
GitHub Issues. Where an API or capability is unsupported, Nakagawa Recomp halts
at a named semantic boundary rather than simulating phantom success.

| Subsystem | State | Current capability & boundaries | Tracking issue |
| :--- | :--- | :--- | :--- |
| Graphics / GE | Partially works | SDL3 and Vulkan hardware rendering with software rasterizer fallback present frames and in-game 3D scenes; direct framebuffer presentation is verified by `display-smoke-v1`. Transient model corruption occurs on main-menu transitions ([#69]); GPU vertex transform & lighting waits for GE correctness and CPU cost measurements ([#318]); real-PSP pixel/command conformance corpus ([#343]) and independent Vulkan re-expression ([#353]) in progress. | [#69](https://github.com/Jstar269/nakagawa-recomp/issues/69), [#318](https://github.com/Jstar269/nakagawa-recomp/issues/318), [#343](https://github.com/Jstar269/nakagawa-recomp/issues/343), [#353](https://github.com/Jstar269/nakagawa-recomp/issues/353) |
| Audio output (SAS / ATRAC3 / Host Audio) | Works | Public builds play sound through the default host audio device via SDL3 ([#301]); runs silently if no device is connected. ATRAC3+ voice lifecycle returns controlled refusal for unsupported formats (`0x80630004`, `0x80630003`) ([#281], [#322]); SAS hardware conformance group planned ([#311]). | [#301](https://github.com/Jstar269/nakagawa-recomp/issues/301), [#311](https://github.com/Jstar269/nakagawa-recomp/issues/311), [#322](https://github.com/Jstar269/nakagawa-recomp/issues/322) |
| Controller input & remapping | Partially works | SDL3 detects connected gamepads and navigates library with fixed default mapping. Dedicated native Controller Settings screen (`VIEW_CONTROLLER_SETTINGS`) provides interactive button remapping for 14 digital PSP controls + analog stick, conflict detection, deadzone & trigger calibration, live input monitor, and guided stick and trigger calibration, and atomic profile persistence. Running games use the saved host input profile. Per-title profiles and further device behaviour are in the works ([#357]). | [#357](https://github.com/Jstar269/nakagawa-recomp/issues/357) |
| Save data (`sceUtilitySavedata` / Memory Stick) | Partially works | `sceUtilitySavedata` writes and reads save files in a local directory; partial `sceIoDevctl` Memory Stick support for `ms0:` and `fatms0:` provides capacity/cluster geometry. Ordinary `ms0:` file I/O and savedata share one Memory Stick namespace ([#334], done); clean-room savedata lineage replacement planned ([#350]). | [#350](https://github.com/Jstar269/nakagawa-recomp/issues/350) |
| Video / FMV / PSMF (`scePsmf`, `sceMpeg`) | Partially works | Host-HLE PSMF playback (MPEG-4 AVC / H.264 via Media Foundation and standalone decoders) plays video cutscenes in tested titles. PSMF MPEG-PS parser hardening with independent PES/pack fixtures ([#288]); MPEG YCbCr/CSC/PCM HLE semantics validation ([#302]); portable H.264 decoder backend ([#283]); A/V presentation timing reconciliation ([#279]); guest PRX execution for `scePsmf_library.prx` ([#286]). | [#279](https://github.com/Jstar269/nakagawa-recomp/issues/279), [#283](https://github.com/Jstar269/nakagawa-recomp/issues/283), [#286](https://github.com/Jstar269/nakagawa-recomp/issues/286), [#288](https://github.com/Jstar269/nakagawa-recomp/issues/288), [#302](https://github.com/Jstar269/nakagawa-recomp/issues/302) |
| System fonts & Typography (`sceFont`, `libfont.prx`, PGF) | Partially works | Native player UI renders using platform system fonts (or fallback debug text) with zero bundled proprietary fonts. Authentic in-game typography requires user-supplied Sony PSP firmware PGF fonts (`jpn0.pgf`, `ltn0.pgf`) imported via `python tools/nk_cli.py fonts import <folder>` ([#300]). Clean-room open-font to PGF converter ([#313]), public PGF reader ([#349]), and guest `libfont.prx` startup without ready-flag bypass ([#299]) in progress. | [#299](https://github.com/Jstar269/nakagawa-recomp/issues/299), [#300](https://github.com/Jstar269/nakagawa-recomp/issues/300), [#313](https://github.com/Jstar269/nakagawa-recomp/issues/313), [#349](https://github.com/Jstar269/nakagawa-recomp/issues/349) |
| Networking / WLAN (`sceNet`, `sceNetAdhoc`, `sceNetApctl`) | Not started | All networking APIs are unimplemented. Network module loading via `sceUtilityLoadNetModule` and `sceUtilityUnloadNetModule` returns controlled refusal (`0x80110001` `SCE_ERROR_UTILITY_INVALID_STATUS`). Network sockets, ad-hoc, and infrastructure return unsupported; no networking stubs or fake connections are provided. | [#281](https://github.com/Jstar269/nakagawa-recomp/issues/281), [#307](https://github.com/Jstar269/nakagawa-recomp/issues/307) |
| CPU execution (AOT translation & Interpreter floor) | Works | Two-phase pipeline translates MIPS instructions to portable C chunks (`tools/codegen.py`). Production fail-closed interpreter floor executes valid AOT misses across both CALL and TAIL crossings ([#116], [#127], [#128]). LLE Phase 1 provides COP0 and exception transfer metadata behind opt-in flags. Full authentic LLE exception semantics default ([#321]); INTC interrupt delivery ([#325]); independent reference interpreter ([#345]). | [#116](https://github.com/Jstar269/nakagawa-recomp/issues/116), [#127](https://github.com/Jstar269/nakagawa-recomp/pull/127), [#128](https://github.com/Jstar269/nakagawa-recomp/pull/128), [#321](https://github.com/Jstar269/nakagawa-recomp/issues/321), [#325](https://github.com/Jstar269/nakagawa-recomp/issues/325), [#345](https://github.com/Jstar269/nakagawa-recomp/issues/345) |
| VFPU (Vector Floating Point Unit) | Works | Scalar VFPU translation and interpreter covering arithmetic, transforms, and trigonometric operations with hardware-measured bit-exact lookup tables (NaN/Inf quieten settled on PSP-3000 ARK-5 silicon, [#40]). Second-title semantic coverage ([#326]); SIMD fast paths ([#292]); clean-room lineage replacement ([#347]). | [#40](https://github.com/Jstar269/nakagawa-recomp/issues/40), [#292](https://github.com/Jstar269/nakagawa-recomp/issues/292), [#326](https://github.com/Jstar269/nakagawa-recomp/issues/326), [#347](https://github.com/Jstar269/nakagawa-recomp/issues/347) |
| Thread scheduler & Kernel synchronization | Works | Cooperative multi-threaded scheduler supporting threads, semaphores, mutexes, event flags, message boxes, and VBLANK wakeups. Hardware-measured thread attributes (CT/ST [#46]). Scheduler liveness/starvation workload coverage ([#290]); unregistered kernel object models ([#339]); clean-room scheduler replacement spec ([#340]). | [#290](https://github.com/Jstar269/nakagawa-recomp/issues/290), [#339](https://github.com/Jstar269/nakagawa-recomp/issues/339), [#340](https://github.com/Jstar269/nakagawa-recomp/issues/340) |
| Filesystem & Disc I/O (ISO9660, XB archives, VFS) | Partially works | Project-authored C ISO9660 PVD reader and directory-record walker (`src/player/iso_reader.c`, `nk_iso_extract_game`); project-authored XB archive extractor (`src/core/nk_xb.c`). Moving loose-disc layout rules out of generic HLE into validated title configuration ([#289]); archive-backed direct VFS to avoid tens of thousands of loose pre-extracted files ([#298]). | [#289](https://github.com/Jstar269/nakagawa-recomp/issues/289), [#298](https://github.com/Jstar269/nakagawa-recomp/issues/298) |
