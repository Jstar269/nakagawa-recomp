# Inherited modified-file notices

This campaign makes the public-safe inherited-file notices explicit. It is a
provenance and publication gate, not legal advice or a conclusion that any
file is legally independent, derivative, or cleared for redistribution.

## Bounded inventory

The inventory is rooted at public commit
`40c67aa066f904427f4faccf988849be31dde332` and compares tracked public paths
with sal063/PSP-recompilation-project commit
`da17b0e1db209206a407d097d132201e516e3855`. It records 46 public paths:

- 43 textual source paths (`.c`, `.h`, `.cpp`, Python, and GLSL);
- two generated SPIR-V embeds and the generated `src/rt/nid_names.h` header.

The generated records are retained for provenance but are not hand-edited.
The header is regenerated by `tools/gen_nidnames.py`; the two SPIR-V arrays are
represented by the GLSL source records. Private PGF/PGD implementations, keys,
fonts, game inputs, captures, oracle traces, and other ignored material are
outside this public inventory.

The baseline had 39 materially modified textual paths without an explicit
modified-file sentence, four bounded notice-only paths, and one unresolved
deeper-provenance path (`src/rt/audio.c`). The four notice-only paths retain
their SPDX and immediate sal063 attribution without asserting a modification
date. The final counts and per-path evidence are machine-readable in
[`MODIFIED_FILE_NOTICES.json`](MODIFIED_FILE_NOTICES.json).

## Notice contract

The campaign preserves each file's existing SPDX identifier and copyright
lines, adds the immediate upstream line where it was absent, and adds this
short notice to materially modified textual files:

```text
Modified by Nakagawa Recomp contributors, YYYY-MM-DD.
See NOTICE.md for upstream lineage and modification provenance.
```

The date is the latest available public-history commit date touching that path
before the campaign. This is a reproducible evidence choice, not a claim that
the date is the only legally relevant date. Existing deeper PPSSPP statements
remain in place; sal063 remains the immediate upstream in the attribution
chain. Shader files keep `#version` as their first line.

The exact GPLv2 text is retained at
[`THIRD_PARTY_LICENSES/GPL-2.0.txt`](../../THIRD_PARTY_LICENSES/GPL-2.0.txt),
alongside the repository-level GPLv3 text, sal063 credits, and `NOTICE.md`.
Per-file `GPL-2.0-or-later` identifiers are intentionally not rewritten to
the repository-level GPLv3 identifier.

## Evidence and limits

GPLv2 section 2(a) and GPLv3 section 5(a) contain modified-file notice
requirements. FSF's source-file guidance also recommends a copying-permission
pointer at the beginning of each source file. The audit records those sources
and checks the selected strings; it does not implement an algorithm to decide
whether a file is an independent work or a derivative work.

`src/rt/audio.c` remains unresolved at the deeper PPSSPP layer: sal063 is the
known immediate upstream, but sal063's own credits do not list this file as a
PPSSPP translation. The manifest deliberately keeps that uncertainty visible.
The four bounded original-candidate tools listed in `NOTICE.md` are recorded
as candidates only, not as legal independence findings.

Run the gate against working-tree bytes with
`python tools/modified_file_notice_audit.py --worktree`, or against staged
blobs with `python tools/modified_file_notice_audit.py --tracked-only`.
The staged form is installed in the pre-commit and pre-push hooks. It checks
the manifest, required license/notice files, SPDX lines, immediate upstream
attribution, explicit modification sentences, generated-source presence, and
the exact notice pointer.

## Non-goals

This campaign does not resolve PGF/JPCSP licensing (#98), replacement-font
provenance (#99), full-history privacy review (#102), PGD/amctrl provenance
(#104), DCO attestations, maintainer approval, or private-repository
backporting. A public pull request and passing exact-head CI are evidence for
review; they are not a legal clearance or an automatic merge authorization.
