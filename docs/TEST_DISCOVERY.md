# Python test-discovery contract

The authoritative Python suite is:

```text
python -m unittest discover -s tools -p 'test_*.py'
```

`tools/discovery_contract.py` records two deliberately different inventories:

* Inventory A is the pre-run `unittest.TestLoader.discover()` case list.
* Inventory B is the set of cases that reach the runner's `startTest` hook.

Inventory B is the count represented by unittest's `Ran N tests` summary. A
loader-only case is not silently deleted from the matrix; it must be explained
by a class/module-level skip or the contract check fails.

The machine-readable inventories are generated by

The `--assert-contract` mode requires every loader-only ID to belong to an
observed class-level skip and rejects authoritative-only IDs or suite failure.
