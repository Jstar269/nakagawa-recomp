Nakagawa Recomp GitHub

Play your PSP games as native PC programs.

Nakagawa Recomp takes a PSP game you own and translates its code into a Windows program, once, before you play. It isn't an emulator. Version 0.0.1 is the first preview, and most games don't run yet. See what works.

How it works

  1. Add your game

    Drag a game you own into the player. It checks the game and gets it ready, all on your PC.

  2. Build it

    One button translates the game's code into C and compiles it into a Windows program. It takes a few minutes and needs no internet: the build tools come with the download.

  3. Play

    Start the game from your library. If it needs something Nakagawa can't do yet, it stops and tells you what's missing.

The matching decomp behind it

Hot Shots Tennis also has a project of its own: hst-decomp, a matching decompilation that rebuilds the game's code as C and C++ that compiles back to the exact original bytes. On 27 October 2026 it had 35.9% of the game's code matched. The two projects share findings, not code: no decomp source is copied into Nakagawa, which is meant for any PSP game.

Help out

Nakagawa is built in the open, and testing is the biggest help right now. Try a game you own and tell us how far it gets, report a bug, or pick up an issue.
