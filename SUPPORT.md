# Getting help

Nakagawa Recomp is a small, early project run by one maintainer. This page says where to take each kind of
question. Please do not share game files, decrypted modules, private paths or personal data in any public place.

| You want to | Go to |
| --- | --- |
| Set the player up or build it | [`docs/SETUP.md`](docs/SETUP.md) and [`docs/YOUR_OWN_GAMES.md`](docs/YOUR_OWN_GAMES.md) |
| Know whether a game works | [`docs/COMPATIBILITY.md`](docs/COMPATIBILITY.md) |
| Fix a Windows build problem | [Windows host pitfalls](docs/SETUP.md#windows-host-pitfalls) |
| Find a barrier, or say something is hard to use | [Accessibility barrier form](https://github.com/Jstar269/nakagawa-recomp/issues/new?template=accessibility.yml), and [`ACCESSIBILITY.md`](ACCESSIBILITY.md) |
| Report a bug | [Bug report form](https://github.com/Jstar269/nakagawa-recomp/issues/new?template=bug_report.yml) after searching [open issues](https://github.com/Jstar269/nakagawa-recomp/issues) |
| Suggest a feature | [Feature request form](https://github.com/Jstar269/nakagawa-recomp/issues/new?template=feature_request.yml) |
| Report that you ran the release smoke test | [Smoke test report form](https://github.com/Jstar269/nakagawa-recomp/issues/new?template=smoke_test_report.yml) |
| Contribute a change | [`CONTRIBUTING.md`](CONTRIBUTING.md) |
| Report a security vulnerability, or a rights-holder concern | [`SECURITY.md`](SECURITY.md): privately, never in a public issue |
| Report a conduct problem | [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) |

There is no chat server, forum or support email, and there is no paid support. Answers come from the maintainer
when time allows, so please search the documentation and existing issues first. A question that other people will
have too is welcome as an issue, and a fix to the documentation that would have answered it is even better.
